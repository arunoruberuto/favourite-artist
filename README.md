# Favourite Artist Intro – Bob Ross

このプロジェクトは、私が高校の頃から尊敬している画家 **ボブ・ロス (Bob Ross)** を紹介するウェブサイトです。自主学習として、学校の課題以上の表現に挑戦しました。

## 学んだこと

- ページに入ったときに 自動再生する音楽を試してみました 
- 初めてSVG グリッドを使って、ホバー時に絵画プレビューを表示する  
- 初めてJSONを使ってボブ・ロスの絵画リストを管理する
- 画像スライドショーの上に、流れる小さな雲のアニメーションを実装  
- カードにホバーしたとき、中身 (説明など) を 違う内容で表示させるエフェクト

## 技術スタック

- HTML  
- CSS (Grid, アニメーション)  
- SVG  
- JavaScript（Vanilla）  
- JSON

## 目的

- Web制作への理解を深める  
- 自分の好きなアーティスト（Bob Ross）を表現する  
- UI / アニメーションの練習プロジェクトとして
